# Lola England

Girls' T-shirt e-commerce website built with Next.js.

Current build includes a responsive storefront, product cards, search, browser wishlist, shopping bag and an admin starter page.

Supabase backend is connected for authentication, products, storage, customers and orders. The project has the initial ecommerce database schema and starter products configured.

Run locally:
npm install
npm run dev

Deployment: Vercel is connected to the GitHub repository, so pushes to main trigger a new deployment.
