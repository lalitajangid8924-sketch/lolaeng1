# Lola England

Girls' T-shirt e-commerce website built with Next.js.

Current build includes a responsive storefront, product cards, search, browser wishlist, shopping bag and an admin starter page.

Supabase is intended for authentication, products, storage, customers and orders. The connected Supabase account currently has no project available, so backend wiring is the next setup step.

Run locally:
npm install
npm run dev
